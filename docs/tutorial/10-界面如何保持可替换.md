# 10 界面如何保持可替换

**换界面为何不改循环？**

> 定位：我们在全局图的界面格，看展示与循环的契约隔离。

两契约：`EventSink:19`（`Agent→UI` 的 `on_stream_event/on_tool_start/on_tool_result/on_compaction`）与 `UIPort:43`（`App→UI` 的 `banner/status_line/ask_permission`），合为 `UIFrontEnd`。`InteractiveApp:33` 用同一对象兼任，核心只认契约。

`ConsoleUI:42` 主线程直出 `Rich`，`Prompt.ask` 阻塞；`TextualUI:32` 经 `MiniTUI.post:157` 的单点线程判断（`call_from_thread` 禁在 UI 线程调）回投，`_PendingPrompt` 以 `Event` 挂起工作线程、`on_permission_bar_answered:222` 收尾。

状态栏经 `port.py:44` 的 `cache_label/fmt_tokens` 渲染 `cache 12.3Kr/4.5Kw`（`widgets.py:153` `ContextBar` 同款，`in/out + cache + ctx`）。

`cli/commands.py:32` 的斜杠分发仅依赖 `UIPort`，故同表在两前端一致。
