# 02 五分钟跑起来

**如何用最短路径验证链路是通的？**

## 装好

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
python -m minicode --help
python -m minicode tools   # 应见 read/write/edit/apply_patch/glob/grep/bash
```

`pyproject.toml` 的 `minicode = "minicode.cli.main:app_entry"` 让 `python -m minicode` 与 `minicode` 等价。

## 配好

```bash
minicode providers login   # 选预设或自定义 OpenAI 兼容地址，填 Key
minicode models            # 见 * provider [openai_compat, key-ok]: xxx 即生效
```

配置优先级在 `src/minicode/config/settings.py`：`--set` > `MINICODE_*` > `./.minicode/config.yaml` > `~/.minicode/config.yaml` > 内置。越近命令行越优先。

## 跑通

```bash
minicode run "用一句话介绍你自己"   # 无工具的最小循环
minicode                            # 类 Aider 的 REPL
minicode tui                        # 可选全屏，左侧会话
```

`/` 触发补全，`/model` 切模型，`/permission` 看规则，都经 `src/minicode/cli/commands.py` 的 `UIPort` 契约。

## 在哪里

```bash
minicode config path   # 全局与项目级文件
minicode config show   # 合并后的最终配置
```

所有落盘收于单根（`platformdirs` 默认或 `MINICODE_DATA_DIR`），便于测试隔离。`grep` 已在后台换为 `ripgrep` 快径（尊重 `.gitignore`，跳过 `SKIP_DIR_NAMES`），无 `rg` 时回落纯 Python，行为一致；需强制回落设 `MINICODE_NO_RIPGREP=1`（`src/minicode/tools/search_tools.py:1`）。
