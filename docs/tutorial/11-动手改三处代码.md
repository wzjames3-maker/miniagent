## 加 Tool

`mytools.py`：

```python
from minicode.tools.base import BaseTool, ToolResult
class ShoutTool(BaseTool):
    name="shout"; permission="read"; description="Shout."
    parameters={"type":"object","properties":{"text":{"type":"string"}},"required":["text"]}
    def run(self, args, ctx): return ToolResult(title="shout", output=args["text"].upper())
def register_tools(r): r.register(ShoutTool())
```

`config.yaml: tools.extra_modules: [mytools]` 经 `registry.py:75` 的 `load_module` 加载。`minicode tools | grep shout` 验证，无需改 `Agent`。
